#   Intended liftoff (Apollo 7):  1968-10-11 15:02:45
#   Simulation start (on pad):    1968-10-11 14:57:45   (= liftoff − 300 s)
#   Plant LaunchDate / T_L′:      matches sim start; liftoff at elapsed ≈ 300 s
#   Pad-load uplink:              sim t ≈ 15 s  (wall ≈ 14:58:00)
#
# TEPHEM (CMC clock-zero epoch, cs since 1968-07-01 00:00):
#   Set to **sim start** (14:57:45), not liftoff.  P11 adds TIME at liftoff so
#   TEPHEM becomes the liftoff epoch when the clock has run ~300 s.  Matches
#   SaturnIBStack LaunchDate = {1968,10,11,14,57,45}.
#
# Geometry (synthesized from TM-X-62831 / as205TmX62831Presettings.ts):
#   LAUNCHAZ  = 72° flight azimuth E of N
#   AZIMUTH   = −80°  (CSM +Z; pad-oriented LV azimuth 100° − 180° mate)
#   LATITUDE  = 28.521963°  (Table 3B φ_L)
#   PADLONG   = −80.561141° (LC-34; tn-hold cite, matches prior pad)
#
# AZO / UNITW / AXO status (verified against virtualagc Colossus249 sources):
#
# AZO (01711-01712) is "ANGLE BETWEEN THE X AXIS OF BASIC REF COORDINATE SYSTEM
# AND THE X AXIS OF THE EARTH-FIXED COORDINATE SYSTEM AT TEPHEM" per
# PLANETARY_INERTIAL_ORIENTATION.agc — i.e. GMST at TEPHEM, DP REVS B-0
# (fraction of a full revolution).
#
# The AGC's inertial subsystem (ISS) is aligned at liftoff / P02 completion
# and the P11 start aligns with the liftoff epoch; there is NO "GRR analog"
# in the AGC that would require re-anchoring AZO relative to T_L' the way the
# plant anchors its LVDC frame.  The 300 s sim-start-to-liftoff offset is
# accounted for naturally by AGC-elapsed time flowing through
# AZ = AZO + ω_E · T in EARTHMX — no manual Earth-rate tweak is needed on
# the pad-loaded AZO.
#
# The currently-loaded value (hi=30636, lo=33227) = 0.7753 rev ≈ 279.086°
# is Luminary069's documented Apollo 10 sample value and is NOT correct for
# our TEPHEM.  Correct value for TEPHEM = 1968-10-11 14:57:45 UT:
#     GMST   = 244.697257° = 0.6797146 rev
#     encoded: hi=25600 lo=16153  (DP REVS B-0)
# (Verification: round-trip quantization error ~0.001 arcsec.)  To apply:
#   01711E 25600E E
#   01712E 16153E E
# This is left unmodified below pending validation against a run.
#
# UNITW (01713-01720): unit Earth polar axis in BRCS.  Pure +Z is correct
# when BRCS X points to Mean Equinox (not pad-local meridian); no epoch
# adjustment needed beyond millennium-scale precession.
#
# PGNCSALT (P11 pad altitude) is absent from this pad load.  Our pad
# altitude ~34.7 m encodes to DP B-29 as essentially zero (hi=0, lo=21 oct);
# omitting it is equivalent to zero and is harmless at orbital scales.
#
